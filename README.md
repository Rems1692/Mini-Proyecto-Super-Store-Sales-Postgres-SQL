# 📊 Super Store Sales Analysis - PostgreSQL

## Objetivo

Analizar el comportamiento de las ventas de una empresa utilizando PostgreSQL para responder preguntas de negocio mediante consultas SQL.

## Herramientas

- PostgreSQL
- SQL
- Git
- GitHub

## Preguntas de negocio

✔ ¿Cómo está el negocio?

✔ ¿Cómo han evolucionado las ventas?

✔ ¿Quién compra?

✔ ¿Qué se vende?

✔ ¿Dónde se vende?

✔ ¿Qué tan rentable es el negocio?
