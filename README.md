## Objetivo

Analizar el comportamiento de las ventas de una empresa utilizando PostgreSQL para responder preguntas de negocio mediante consultas SQL.

## Herramientas

- PostgreSQL
- SQL

✔ ¿Cómo han evolucionado las ventas?

✔ ¿Quién compra?

✔ ¿Dónde se vende?
